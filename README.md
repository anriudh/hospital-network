# Hospital Network (Cisco Packet Tracer)

Computer Networks group project, Manipal Institute of Technology, Bengaluru.

Design and simulate a secure, fault-tolerant hospital network in Cisco Packet Tracer using VLANs, redundant switching, and ACLs.

## Folders
- `pkt/` Packet Tracer files, one version per build stage
- `configs/` running config of every device
- `docs/` addressing, VLAN and ACL tables, passwords, walkthrough, report outline
- `evidence/` raw output of every test
